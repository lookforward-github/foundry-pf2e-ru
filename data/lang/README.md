# data/lang — база перевода интерфейса

Сюда кладётся рукописная база перевода UI-строк системы PF2e и ядра Foundry.

- Любое число `*.json`, сливаются в алфавитном порядке имён файлов.
- Формат — обычный i18n Foundry. Поддерживаются и вложенный вид, и плоские
  ключи с точками; при сборке всё разворачивается в плоский.
- Всё это попадает в единственный файл `lang/ru.json`, объявленный в манифесте.

```json
{
  "PF2E": {
    "Actor": { "Character": { "Level": "Уровень" } }
  },
  "CHAT.RollVisibility": "Видимость"
}
```

Приоритет при сборке: листы Google Sheets → **этот слой** → `data/overrides`.
То есть значение отсюда перебивает то, что пришло из таблицы.
