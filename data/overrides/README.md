# data/overrides — точечные правки поверх собранного

Формат тот же, что в [../manual](../manual/README.md), но приоритет выше всех
остальных слоёв. Сюда идёт только то, что нужно перебить, а не целые паки.

Когда это уместно:

- в таблице ошибка, а править её прямо сейчас неудобно;
- API отдаёт неподходящий вариант перевода для конкретного случая;
- нужен временный хотфикс до следующей выгрузки.

Каждая запись здесь — технический долг: при сборке в лог пишется, сколько
значений перебито и какие именно. Разгребайте список и удаляйте записи,
когда исправление доехало до источника.
